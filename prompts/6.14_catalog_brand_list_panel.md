# Каталог: зручніший список брендів — розширення панелі, пошук, закріплені шапка і кнопка

Зручніший список брендів у панелі фільтрів каталогу (frontend/src/features/catalog: FilterPanel.tsx, CatalogPage.tsx, CatalogPage.module.css, catalog.ts, messages.uk.ts). Контекст: CLAUDE.md, ADR-0002 (mobile-first), shared/tokens.css, CSS Modules, motion.

Проблема: після «Показати всі (N)» у групі «Бренд» список брендів стає довгим стовпчиком, і щоб після вибору бренду внизу списку дістатися до «Ціни» чи інших фільтрів, треба довго гортати.

1. Розширення панелі при «Показати всі»:
   - на ноутбуці/десктопі (панель — колонка зліва): після «Показати всі» панель плавно (motion) розширюється приблизно вдвічі, а бренди розкладаються в 2–3 колонки (CSS grid, auto-fill, minmax під найдовшу назву, назви не обрізаються, переносяться). Розширена панель накладається поверх сітки товарів з тінню, а не зсуває її; сітка товарів під нею не стрибає.
   - на телефоні/планшеті (панель — шухляда): шухляда займає всю ширину екрана, бренди в 2 колонки (на 320 px — 1 колонка, якщо назви не влазять).
   - кнопка змінюється на «Згорнути» — повертає панель до звичайної ширини і перших 8 брендів; вибрані бренди при цьому лишаються вибраними і завжди показуються в згорнутому списку (навіть якщо вони не серед перших 8).
   - Esc, ✕ або клік поза панеллю закривають панель як зараз; розширення при наступному відкритті скидається.

2. Щоб інші фільтри були поруч:
   - заголовок «Фільтри» з ✕ і «Скинути все» — закріплений угорі панелі (position: sticky), а внизу панелі закріплена кнопка «Показати N товарів» (на всіх розмірах, не лише на мобільному); вміст між ними прокручується всередині панелі (overflow-y: auto, висота панелі — до висоти вікна мінус шапка).
   - якщо брендів більше 12 — над списком поле пошуку «Пошук бренду» (фільтрує список на льоту, без урахування регістру; «Нічого не знайдено», якщо порожньо).
   - вибір бренду не прокручує панель і не згортає список.

3. Доступність: кнопка «Показати всі / Згорнути» з aria-expanded і aria-controls; поле пошуку з label; при розширенні фокус лишається на кнопці; кількість знайдених брендів оголошується через aria-live="polite".

4. Перевір на ширинах 320, 375, 768, 1024, 1440 px: нічого не виходить за край екрана, немає горизонтального скролу сторінки, ціна й інші групи доступні без довгого гортання.

5. Тести: «Показати всі» розгортає повний список і змінює текст на «Згорнути»; «Згорнути» залишає вибрані бренди видимими; пошук фільтрує список і показує «Нічого не знайдено»; вибір бренду не згортає список.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

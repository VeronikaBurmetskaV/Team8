# Логотипи на плитках брендів: GET /api/brands, логотип сайту джерела в dev-імпорті

Логотипи на плитках брендів. Контекст: CLAUDE.md, docs/architecture/api.md (PublicCard не містить логотип — US-08.2 CL), ADR-0014 (імпорт лише для демо, dev-профіль, дані чужих сайтів ніколи не публікуються), ADR-0004 (JdbcClient, без JPA), Flyway. Плитки — frontend/src/features/catalog/BrandTiles.tsx, монограма лишається запасним варіантом.

Частина A — зареєстровані бренди (зі згодою):
1. Новий публічний ендпоінт GET /api/brands → [{ key, name, logoUrl | null, productCount }] лише для брендів зі станом CONSENTED (згода надана) і з опублікованими товарами. logoUrl — той самий logoDisplayUrl, що в профілі (/api/images/{id} або https-URL бренду). Бренди без згоди — logoUrl: null.
2. Онови api.md (таблиця ендпоінтів і примітку US-08.2: логотип тепер віддається окремим ендпоінтом брендів і лише за згоди) і додай короткий ADR (наступний номер) з причиною рішення. PublicCard не змінюємо.
3. Тести бекенду: без згоди — null; зі згодою — URL; бренди без опублікованих товарів не повертаються.

Частина B — імпортовані бренди (лише dev-демо, ADR-0014):
4. В імпортері (backend/.../catalogimport) при прогоні джерела додатково визначай логотип сайту джерела в такому порядку: JSON-LD Organization.logo → <link rel="apple-touch-icon"> → og:image головної сторінки → favicon. Лише https, через наявний PoliteFetcher (robots.txt, паузи, ліміти). Зображення НЕ копіювати — зберігати тільки URL у таблиці catalog_sources (нова колонка logo_url через Flyway-міграцію).
5. GET /api/brands для імпортованих брендів повертає цей URL лише в профілі dev; у prod/ops — null (як і весь імпорт).
6. Онови ADR-0014 (розділ про дані: тепер також URL логотипа сайту, лише dev).

Частина C — фронтенд:
7. BrandTiles бере дані з GET /api/brands (react-query) і поєднує з brandOptions за brandKey. Якщо є logoUrl — у квадраті логотип (object-fit: contain, світлий фон, відступи, alt «Логотип <назва>», loading="lazy", referrerPolicy="no-referrer"); якщо картинка не завантажилась (onError) або logoUrl немає — монограма, як зараз. Розмір плиток і сітка не змінюються.
8. Тести: логотип показується, коли є URL; при помилці завантаження — монограма; без URL — монограма.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: cd backend && ./mvnw verify, потім npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

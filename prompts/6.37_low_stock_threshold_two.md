# Поріг червоної цифри розмірів: 1–2

Зміна порогу червоної цифри біля кружечків розмірів (stockHint у catalog.ts або shared, CatalogTile, ProductCard, SwipeCard, SavedProducts, messages.uk.ts).

1. Червоний бейдж з числом показується лише коли доступних розмірів 1 або 2 (раніше — 1–3). При 3 і більше — бейджа немає.
2. Поріг винеси в одну константу (наприклад LOW_STOCK_SIZES = 2) і використовуй її скрізь, де перевіряється «мало розмірів» (бейдж, aria-label «Залишилось N розміри», підсвітка кружечків, якщо є).
3. aria-label групи: при 1–2 — з фразою «Залишився 1 розмір» / «Залишилось 2 розміри»; при 3+ — лише перелік доступних розмірів.
4. Онови тести: 3 доступні — бейджа немає; 2 і 1 — є з правильним числом; 0 — «Немає в наявності».

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

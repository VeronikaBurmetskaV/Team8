# Шапка покупця: світла смуга при overscroll і одна стрілка для смужки й розгорнутої шапки

Дві правки липкої шапки покупця (frontend/src/shared/BuyerHeader.tsx, BuyerHeader.module.css, headerState.ts, frontend/src/index.css, shared/tokens.css). Контекст: CLAUDE.md, ADR-0002, CSS Modules, motion. Шапку кабінету бренду не чіпати.

1. Світла смуга над шапкою при прокрутці вгору:
   - якщо на самому верху сторінки ще потягнути вгору (тачпад/колесо на Mac, свайп на телефоні) або швидко гортати вгору, над чорною шапкою видно світлий фон сторінки (смуга ~70 px). Так не має бути — над шапкою ніколи не видно світлого фону.
   - Спершу з'ясуй причину і напиши її мені: «пружинний» overscroll браузера (rubber-band у Safari/Chrome на macOS та iOS), шапка, що в якийсь момент не стоїть на top: 0 (transform/translateY під час анімації, sticky з ненульовим top, проміжок між станами full ↔ compact), чи відступ/маркер у Layout.
   - Виправ саме причину. Для overscroll: overscroll-behavior-y: none на html і body (де підтримується) і додатково фон html — темний (колір шапки) зверху і світлий (фон сторінки) знизу (наприклад linear-gradient з різкою межею або background на html темний + body світлий з min-height: 100dvh), щоб і в Safari, де overscroll-behavior не завжди спрацьовує, при відтягуванні вгору був видний темний колір шапки, а при відтягуванні вниз — світлий фон сторінки.
   - Для анімації: під час переходу full ↔ compact шапка завжди притиснута до top: 0, зверху не з'являється проміжок ні на мить.
   - перевір у Chrome і Safari на Mac (тачпад) і в DevTools на iPhone-розмірі.

2. Стрілка розгортання/згортання — однакова координата x:
   - зараз у тонкій смужці стрілка «⌄» стоїть лівіше, ніж стрілка «⌃» у розгорнутій шапці (яка праворуч від «UA ⌄»). Стрілка в смужці має бути рівно там же по горизонталі, що й у розгорнутій шапці.
   - Зроби це одним елементом: та сама кнопка (один DOM-вузол, який не перемонтовується між станами compact і compactExpanded), абсолютно позиціонована відносно спільного контейнера шапки (той самий right і та сама ширина кнопки в обох станах); змінюється лише поворот іконки (⌄ ↔ ⌃) з плавною анімацією rotate.
   - по вертикалі в смужці стрілка по центру смужки; у розгорнутій шапці — на рівні рядка «КИЇВ / UA», як зараз.
   - у розгорнутій шапці стрілка не перекриває «UA ⌄» і не зсуває його; якщо місця мало (≤ 375 px), рядок міста/мови отримує відступ справа під ширину кнопки.
   - перевір на 375, 768, 1024, 1440, 1920 px: x стрілки в обох станах однаковий (різниця 0–1 px).

3. Тести: стрілка — один і той самий елемент у compact і compactExpanded (не перемонтовується); aria-label змінюється «Розгорнути меню» ↔ «Згорнути меню»; наявні тести шапки проходять.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши причину світлої смуги і змінені файли.

# Каталог: назва бренду на картці — посилання, «сторінка бренду» на головній

Назва бренду на картці каталогу — посилання на одяг цього бренду. Код: frontend/src/features/catalog (CatalogTile.tsx, CatalogTile.module.css, CatalogPage.tsx, catalog.ts), тексти — shared/messages.uk.ts. Фільтр брендів (?brand=<key>, brandOptions, filterCatalog, parseFilters, чіпи) уже зроблений — перевикористай його, нічого не дублюй. Контекст: CLAUDE.md, ADR-0002, shared/tokens.css, CSS Modules. Бекенд не чіпаємо.

1. Назва бренду на картці (CatalogTile, клас .brand):
   - трохи більша (на один крок шкали шрифтів з tokens.css) і трохи жирніша (на один крок font-weight, наприклад з medium на semibold), колір той самий;
   - це посилання (<Link> з react-router) на /?brand=<key>, де key — та сама нормалізація, що в brandOptions (винеси в спільну функцію brandKey(name) у catalog.ts і використовуй її в обох місцях);
   - hover/focus-visible: підкреслення; aria-label «Увесь одяг бренду MINT»;
   - клік по назві бренду не повинен ставити лайк чи робити щось інше з карткою.
   Це ж посилання зроби і на назві бренду в повній картці товару, де вона є (ProductCard на свайпах і в модалці обраного), якщо це не ламає свайп-жести; якщо ламає — лише в каталозі й поясни чому.

2. Перехід скидає інші фільтри: посилання веде рівно на /?brand=<key> (без ціни та інших брендів) і прокручує сторінку на початок.

3. «Сторінка бренду» — це головна з рівно одним вибраним брендом і без інших фільтрів:
   - зверху над сіткою замість звичайного заголовка: маленький надпис «Бренд», під ним назва бренду великим заголовком (h1, шрифт заголовків з tokens.css), поруч кількість товарів («12 товарів»);
   - над заголовком посилання «← Весь одяг», яке веде на / без фільтрів;
   - банер, що веде на свайпи, на сторінці бренду не показувати;
   - чіп цього бренду над сіткою не дублювати (заголовок уже показує бренд); якщо користувач додасть ще фільтр (ціну чи інший бренд) — сторінка знову виглядає як звичайний каталог з чіпами;
   - document.title: «MINT — FULLA».
   - Визначення «це сторінка бренду» — чиста функція в catalog.ts (isSingleBrandView(filters)).
   - Якщо бренду з URL немає серед товарів — «Товарів цього бренду поки немає» і посилання «← Весь одяг».

4. Тести:
   - brandKey однаковий для різного регістру/пробілів;
   - назва бренду на картці — посилання на /?brand=<key>, клік не ставить лайк;
   - на /?brand=<key> показано заголовок бренду, «← Весь одяг», лише товари цього бренду, немає банера;
   - з доданою ціною — звичайний вигляд з чіпами;
   - невідомий бренд — повідомлення про порожній результат.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

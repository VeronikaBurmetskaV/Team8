# «Контактна особа», плитки брендів на головній, підказка над плиткою

Три правки: поле «Контактна особа», плитки брендів на головній, підказка над плиткою. Код: frontend/src/features/cabinet-profile (BrandProfilePage, profileForm.ts), frontend/src/features/catalog (BrandTiles.tsx, CSS Module, catalog.ts — brandOptions, brandKey), запити каталогу і публікації в cabinet-products (queries.ts); бекенд — GET /api/feed, GET /api/brands (якщо є), профіль бренду. Контекст: CLAUDE.md, api.md, ADR-0002, CSS Modules.

1. Прибери поле «Контактна особа» зі сторінки профілю бренду (/brand/profile) разом з його валідацією й текстами. Бекенд-колонку contact_name і поле в реєстрації не чіпай (лише прибери з форми профілю й з PUT профілю на фронтенді, щоб не затирати значення).

2. Плитки брендів на головній (блок «Бренди»):
   - бренд з'являється серед плиток, щойно в нього є хоча б один ОПУБЛІКОВАНИЙ товар, і зникає, коли опублікованих 0; лічильник «N товарів» рахує лише опубліковані;
   - після публікації або зняття з публікації в кабінеті блок брендів і каталог оновлюються без перезавантаження: інвалідуй запити каталогу (/api/feed, /api/brands) у мутаціях publish/unpublish;
   - перевір, що зареєстровані бренди (як «Bevza(demo)») і імпортовані демо-бренди обробляються однаково (один brandKey, без дублів, якщо назва та сама);
   - логотип: якщо в бренду є логотип у профілі (і згода надана) — показуй його; інакше, якщо під час імпорту з сайту бренду знайдено логотип сайту (лише dev, як для демо-брендів) — його; інакше монограма. Розмір і вигляд — як у CHER'17 / One By One зараз.

3. Підказка з назвою над плиткою (зараз при наведенні на MAGNETIC вона з'являється над сусідньою плиткою J. Cook):
   - знайди причину (позиціонування відносно не того елемента, спільний стан, position: absolute без position: relative у батька тощо) і виправ: підказка показується над ТІЄЮ плиткою, на яку наведено, і не виходить за край екрана;
   - якщо підказка дублює назву, яка й так видна під плиткою, — прибери її зовсім (лиши лише для обрізаних довгих назв через title або власну підказку). Поясни вибір.

4. Тести: профіль без поля «Контактна особа»; бренд з 0 опублікованих не показується, з 1 — показується з правильним лічильником; після публікації список брендів оновлюється (інвалідація); пріоритет логотип профілю → логотип сайту → монограма; підказка прив'язана до своєї плитки.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: cd backend && ./mvnw verify (якщо змінював бекенд), npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

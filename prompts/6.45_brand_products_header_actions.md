# Верхня частина сторінки товарів бренду (/brand/products)

Правки верхньої частини сторінки товарів бренду (/brand/products). Код: frontend/src/features/cabinet-products (BrandProductsPage.tsx, CSS Module, queries.ts), useBrandProfile, shared/messages.uk.ts, shared/tokens.css. Контекст: CLAUDE.md, ADR-0002 (кабінет desktop-first), CSS Modules.

1. Заголовок: «Товари бренду BEVZA (demo)» — з назвою бренду з профілю (useBrandProfile). Назва бренду — тим самим шрифтом заголовка, але візуально виділена (наприклад, зеленим кольором з tokens.css або окремим рядком під «Товари бренду», якщо назва довга — обери варіант, що не ламається на вузьких екранах). Поки профіль вантажиться — просто «Товари бренду»; якщо назви немає — без неї. document.title: «Товари BEVZA — FULLA».

2. Кнопки дій — одна група під заголовком, ліворуч, в одному ряду:
   - «Оновити з сайту» (замість «Оновити з сайту зараз») — головна кнопка (зелена, як інші головні кнопки);
   - «Додати вручну» (замість «Додати товар» у правому верхньому куті) — другорядна кнопка з рамкою, поруч з «Оновити з сайту», той самий розмір і висота; наведення — зелена рамка й текст; веде туди ж, куди й раніше (/brand/products/new);
   - прибери стару кнопку «Додати товар» з правого верхнього кута;
   - під кнопкою «Оновити з сайту» (вирівняно по її лівому краю) — дрібним сірим текстом «Оновлено: сьогодні о 18:52» (на крок менший шрифт з tokens.css); під час оновлення — «Оновлюємо…» з індикатором; якщо сайту в профілі немає — замість «Оновити з сайту» підказка «Додайте сайт бренду в профілі» з посиланням, «Додати вручну» лишається;
   - на вузьких екранах кнопки одна під одною на всю ширину.

3. Прибери випадний список «Показати» (фільтр «Усі товари» / «Чернетки з сайту») разом з підписом. Список завжди показує всі товари (порядок: чернетки й опубліковані як зараз, «Немає на сайті» — внизу). Видали код фільтра, який більше не використовується, і пов'язані тексти/тести.

4. Кнопки «Опублікувати вибрані (N)» і «Опублікувати всі чернетки (N)» — лишаються праворуч над таблицею, на тому ж рівні, де був фільтр (тепер ліворуч порожньо — вирівняй групу так, щоб не було дивної порожнечі: наприклад, ліворуч дрібно «47 товарів», праворуч кнопки публікації).

5. Тести: заголовок містить назву бренду; є «Оновити з сайту» і «Додати вручну», немає «Додати товар» і «Оновити з сайту зараз»; дата оновлення під кнопкою; немає списку «Показати»; без сайту в профілі — підказка замість кнопки оновлення.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

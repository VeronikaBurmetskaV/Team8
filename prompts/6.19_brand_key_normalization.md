# Баг: плитки і фільтр брендів не працюють для «CHER'17» і «One By One»

Баг: плитки брендів і фільтр брендів не працюють для деяких брендів — щонайменше «CHER'17» і «One By One» (клік по плитці/чекбоксу не показує їхні товари або показує «Товарів цього бренду поки немає»). Код: frontend/src/features/catalog (catalog.ts — brandKey, brandOptions, parseFilters, filterCatalog, isSingleBrandView; BrandTiles.tsx; FilterPanel.tsx; CatalogTile.tsx). Бекенд не чіпаємо.

1. Спершу знайди причину на реальних даних: запусти бекенд (або подивись відповідь GET /api/feed) і виведи точні значення brandName для цих брендів у всіх товарах — з кодами символів (апострофи ' ’ ʼ `, нерозривні пробіли U+00A0, подвійні пробіли, різний регістр, пробіли на кінцях). Перевір, що відбувається з ключем у URL (кодування апострофа, encodeURIComponent/URLSearchParams) і при поверненні з URL. Напиши мені, що саме було причиною.

2. Виправ brandKey так, щоб однакові бренди завжди давали один ключ:
   - Unicode-нормалізація NFKC;
   - усі види апострофів і лапок (' ’ ‘ ʼ ` ´) → один символ або прибрати;
   - усі види пробілів (включно з U+00A0, U+2009) → звичайний пробіл, кілька пробілів → один, trim;
   - toLocaleLowerCase('uk').
   Ключ у URL кодується/декодується лише через URLSearchParams (без ручного encode), parseFilters порівнює через той самий brandKey.

3. Використовуй ОДНУ функцію brandKey скрізь: плитки, чекбокси фільтра, посилання з назви бренду на картці, filterCatalog, isSingleBrandView, підрахунок у brandOptions. Пошукай і прибери будь-які інші місця, де бренди порівнюються інакше (toLowerCase, ===, trim окремо).

4. Тести на brandKey і на повний сценарій: «CHER'17» / «CHER’17» / «cher'17 » — один ключ; «One By One» / «One By One» / «ONE BY ONE» — один ключ; плитка й чекбокс для цих брендів показують усі їхні товари; посилання /?brand=<key> з апострофом працює після перезавантаження сторінки.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши причину і змінені файли.

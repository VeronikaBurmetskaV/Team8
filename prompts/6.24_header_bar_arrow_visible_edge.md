# Шапка покупця: вирівнювання стрілки в тонкій смужці і рамка фокуса (повторно)

Вирівнювання стрілки в тонкій смужці липкої шапки (frontend/src/shared/BuyerHeader.tsx, BuyerHeader.module.css). Контекст: CLAUDE.md, CSS Modules, shared/tokens.css.

1. Кнопка-стрілка «Розгорнути меню» в компактній смужці зараз стоїть лівіше, ніж правий край елементів повної шапки. Її правий край має збігатися по горизонталі (однакова координата x) з правим краєм крайніх правих елементів повної шапки — перемикача мови «UA ⌄» і іконки профілю.
   - Не підбирай відступ «на око»: смужка і повна шапка мають використовувати той самий контейнер (ту саму max-width, padding-inline, safe-area) — винеси його в спільний клас/CSS-змінну, щоб вирівнювання трималось на всіх ширинах.
   - Іконка стрілки всередині кнопки вирівняна по правому краю так само, як іконка профілю у своїй кнопці (однаковий розмір кнопки й внутрішні відступи).
   - Логотип FULLA у смужці лишається рівно по центру.

2. Навколо стрілки зараз видно рамку (вертикальні лінії зліва й справа) навіть після кліку мишею. Рамка фокуса має бути лише при навігації з клавіатури (:focus-visible), а не після кліку; у звичайному стані без рамки.

3. Перевір на ширинах 375, 768, 1024, 1440, 1920 px: правий край стрілки в смужці = правий край «UA ⌄»/іконки профілю в повній шапці (різниця 0–1 px). Додай у відповідь, як перевірено.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

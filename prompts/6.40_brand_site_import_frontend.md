# Інтерфейс імпорту товарів з сайту бренду (фронтенд)

Інтерфейс імпорту товарів з сайту бренду (фронтенд). Бекенд уже зроблено (див. новий ADR про імпорт, api.md: /api/brand/site/verify, /api/brand/import, /api/brand/import/status, публікація). Код: frontend/src/features/cabinet-home (BrandHomePage), cabinet-profile, cabinet-products, shared/messages.uk.ts. Контекст: CLAUDE.md, ADR-0002 (кабінет desktop-first), tokens.css, CSS Modules, react-query, motion.

1. Головна кабінету (/brand), у картці «Товари» або окремою карткою під шапкою профілю — «Імпорт з сайту»:
   - сайт не підтверджено: крок 1 «Підтвердіть, що сайт ваш» — три способи (мета-тег з кнопкою «Скопіювати», файл fulla-verification.txt з кнопкою «Завантажити файл», або автоматично через пошту на домені сайту), кнопка «Перевірити»; зрозумілі помилки;
   - сайт підтверджено: кнопка «Імпортувати товари з goldi.ua», необов'язкове поле «Посилання на товарний фід» (з підказкою, що це і де взяти в Horoshop/Prom/Shopify);
   - під час імпорту: прогрес-стан (опитування статусу кожні 3 с, без блокування сторінки), після — підсумок «Знайдено 32, додано 28 як чернетки, оновлено 4, пропущено 3 (не одяг)» і кнопка «Переглянути чернетки»;
   - час останнього імпорту і примітка про автооновлення раз на добу.
2. Сторінка товарів (/brand/products): фільтр «Чернетки з сайту»; чекбокси для вибору кількох товарів; кнопки «Опублікувати вибрані» і «Опублікувати всі»; позначка «з сайту» на імпортованих; якщо згоди немає — публікація неактивна з поясненням і посиланням на згоду.
3. Редагування імпортованого товару працює як звичайного; після ручної зміни поля — позначка «змінено вручну, не оновлюється з сайту».
4. Доступність: прогрес і підсумок — role="status"/aria-live; кнопки з чіткими підписами.
5. Тести: усі стани (не підтверджено, підтвердження, помилка, імпорт триває, підсумок), масова публікація, блокування публікації без згоди.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

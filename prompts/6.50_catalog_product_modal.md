# Повна картка товару з каталогу на головній

Відкриття повної картки товару з каталогу на головній (/). Код: frontend/src/features/catalog (CatalogTile.tsx, CatalogPage.tsx), shared/SavedProducts (ProductModal — повна картка з перевертанням і розмитим фоном, що вже використовується в обраному), shared/ProductCard, shared/messages.uk.ts. Контекст: CLAUDE.md, ADR-0002 (покупець mobile-first), CSS Modules, motion.

ВАЖЛИВО: вигляд плитки каталогу НЕ змінювати — ні розміри, ні фото, ні тексти, ні сердечко, ні кружечки розмірів, ні назву бренду. Лише додати відкриття повної картки.

1. Клік (або Enter/Space з клавіатури) по фото чи будь-якій частині плитки, КРІМ сердечка, посилання на бренд і кнопок, відкриває повну картку товару — ту саму модалку, що в обраному (ProductModal / ProductCard з перевертанням): фото, назва, бренд, ціна, розміри, на звороті — уся детальна інформація, кнопка «Перейти на сайт бренду». Перевикористай наявний компонент, нічого не дублюй.
   - фон сторінки розмивається і затемнюється, скрол сторінки блокується, поява через motion; закриття — хрестик, Esc, клік по фону; фокус повертається на плитку;
   - сердечко в модалці працює так само, як на плитці (синхронно, з тим самим лімітом вподобаного);
   - клік по сердечку чи назві бренду на плитці — як і зараз (лайк / перехід на бренд), модалку не відкриває (зупинити спливання події).

2. Посилання на картку: при відкритті в URL додається ?product=<id> (через URLSearchParams, разом з наявними фільтрами); «Назад» у браузері закриває модалку; відкриття сторінки з ?product=<id> одразу показує картку (якщо товар є в каталозі, інакше параметр ігнорується). Фільтри при цьому не скидаються.

3. Доступність: плитка — role="button" (або обгортка-кнопка) з aria-label «Відкрити картку: <назва>», tabIndex=0, але сердечко й посилання бренду лишаються окремими елементами, доступними з клавіатури; модалка — role="dialog", aria-modal, aria-labelledby на назву товару.

4. Тести: клік по фото відкриває модалку з правильним товаром; клік по сердечку і назві бренду не відкриває модалку; Esc і «Назад» закривають; ?product=<id> відкриває картку при завантаженні; знімок/перевірка, що розмітка плитки не змінилась (ті самі елементи й класи).

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

# Шапка покупця: розгорнута смужка замінюється повною шапкою

Виправлення розгортання липкої шапки покупця (frontend/src/shared/BuyerHeader.tsx, BuyerHeader.module.css, headerState.ts). Контекст: CLAUDE.md, ADR-0002, CSS Modules, motion. Шапку кабінету бренду не чіпати.

Проблема: у стані «смужка розгорнута» (compactExpanded) повна шапка рендериться ПІД смужкою — у результаті два логотипи FULLA (маленький у смужці й великий нижче) і шапка вдвічі вища, ніж нагорі сторінки.

Як має бути:
1. У стані compactExpanded смужка ЗАМІНЮЄТЬСЯ повною шапкою, а не доповнюється нею: на екрані рівно один логотип FULLA (великий, з SWIPING), один ряд міста/мови й іконок — точно так само, як шапка нагорі сторінки.
2. Висота розгорнутої шапки = висота повної шапки нагорі сторінки (той самий компонент/розмітка і ті самі стилі, без додаткових відступів); не дублюй розмітку — один <header>, який змінює стан.
3. Кнопка «Згорнути меню» (стрілка вгору) лишається, але всередині повної шапки — у правому верхньому куті, вирівняна з рядком міста/мови і не зсуває його; в усіх інших станах (full нагорі сторінки) стрілки немає.
4. Розгорнута шапка лежить поверх контенту (fixed, top: 0) і не зсуває сторінку; перехід смужка ↔ повна — та сама плавна анімація, що й при прокрутці (висота й масштаб логотипа), без «другої» шапки, що виїжджає знизу.
5. Згортання як і раніше: стрілка, Esc, клік поза шапкою, перехід на іншу сторінку, прокрутка вниз > ~40 px.
6. Тести: у compactExpanded у DOM рівно один логотип FULLA і один <header>; висота/класи збігаються зі станом full; стрілка є лише в compactExpanded; наявні тести headerState проходять.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

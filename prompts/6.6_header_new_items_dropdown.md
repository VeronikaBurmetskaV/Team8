# Шапка покупця: лічильник нових товарів і випадні списки «місто»/«мова»

Дві правки шапки покупця (frontend/src/shared/BuyerHeader.tsx). Контекст: CLAUDE.md, ADR-0002 (покупець mobile-first), shared/tokens.css, CSS Modules, motion. Бекенд не чіпаємо.

1. Лічильник над іконками обраного показує НОВІ товари, а не загальну кількість.
   Зараз IconLink отримує count={favorites.length} і count={swipeFavorites.length}, тобто всю довжину списку.
   Потрібно (окремо для кожної іконки: «обране зі свайпів» і «обране»):
   - лічильник = кількість товарів, доданих у список після останнього відкриття відповідної сторінки (/favorites або /swipe-favorites);
   - коли користувач відкриває сторінку (клік по іконці чи прямий перехід за адресою) — лічильник скидається; при 0 нічого не показувати (як зараз, бейдж прихований);
   - якщо потім додати ще 1 товар — показується 1;
   - якщо видалити товар, який ще «новий», — лічильник зменшується; видалення старих товарів лічильник не змінює.
   Реалізація: зберігати набір id товарів, які користувач уже «бачив» на сторінці, через наявний shared/storage.ts (окремий ключ на кожен список); бейдж = кількість id у списку, яких немає в цьому наборі. Після відкриття сторінки набір = поточні id списку. Логіку винеси в хук (наприклад useNewItemsCount у shared/productLists.ts або поруч), не в компонент шапки.
   Онови aria-label іконки (t.withCount), щоб скрінрідер теж чув кількість нових.
   Тести: додали 4 → 4; відкрили сторінку → бейджа немає; додали 1 → 1; видалили новий → 0; перезавантаження сторінки зберігає стан.

2. Випадні списки «місто» і «мова» (UA/EN) у шапці.
   Зараз це нативні <select>; на macOS система відкриває список поверх поля (вибраний пункт «КИЇВ» перекриває кнопку й сусідні елементи). Треба, щоб список відкривався ПІД кнопкою і нічого не перекривав.
   - Зроби один перевикористовуваний компонент у shared/ (наприклад Dropdown): кнопка з поточним значенням і стрілкою, по кліку під нею з'являється список (position: absolute, top: 100% + невеликий відступ, вирівняний по правому краю кнопки, z-index над контентом сторінки).
   - Стиль у палітрі tokens.css (фон, бордер, радіус, тінь як у карток), вибраний пункт позначений галочкою, hover/focus-стани; поява через motion (fade + невеликий зсув вниз). Ніякого яскравого рожевого — лише кольори з tokens.css.
   - Доступність: кнопка aria-haspopup="listbox", aria-expanded; список role="listbox", пункти role="option", aria-selected; стрілки вгору/вниз, Enter/Space вибирають, Esc і клік поза списком закривають, фокус повертається на кнопку.
   - Список не виходить за край екрана на мобільному (320 px) і в бургер-меню.
   - Заміни ним обидва <select> (місто й мова), поведінка вибору мови та міста лишається як зараз; прихований label для скрінрідерів зберегти.
   - Тести компонента: відкриття, вибір пункту, Esc, клавіатура.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

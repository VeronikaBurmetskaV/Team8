# Головна: блок «Бренди» з квадратними плитками брендів

Блок «Бренди» на головній (/) — квадратні плитки брендів, клік веде на одяг бренду. Код: frontend/src/features/catalog (CatalogPage.tsx, catalog.ts, новий компонент BrandTiles.tsx + BrandTiles.module.css), тексти — shared/messages.uk.ts. Контекст: CLAUDE.md, ADR-0002 (mobile-first), shared/tokens.css, CSS Modules, motion. Бекенд і api.md не змінюємо.

Вже є: фільтр брендів, brandOptions(items) і brandKey(name) у catalog.ts, сторінка бренду /?brand=<key> (isSingleBrandView). Перевикористай їх, нічого не дублюй.

1. Дані:
   - список брендів — з того ж GET /api/feed через brandOptions (унікальні, без урахування регістру, з кількістю товарів), відсортовані за алфавітом;
   - логотипів у публічних даних немає (api.md: PublicCard не містить логотип, US-08.2 CL) — НЕ додавай запитів до бренд-профілів і не змінюй API.

2. Плитка бренду:
   - квадрат (aspect-ratio: 1/1), заокруглені кути як у карток каталогу, тонка рамка з tokens.css;
   - у центрі — монограма: 1–2 перші літери назви (для назв з кількох слів — перші літери двох слів, напр. «Lucky Humanoid» → «LH», «CHER'17» → «CH»), великим шрифтом заголовків з tokens.css;
   - фон монограми — детермінований колір з палітри tokens.css (brown, beige, warm-gray, olive/green, accent), обраний за хешем brandKey, щоб у бренду завжди був той самий колір; колір тексту з контрастом ≥ 4.5:1 до фону;
   - під монограмою (у плитці, знизу) — повна назва бренду (обрізається з «…» в один рядок, повна назва в title/aria-label) і кількість товарів дрібно («5 товарів», правильні відмінки: 1 товар, 2–4 товари, 5+ товарів — якщо в проєкті вже є функція відмінювання, використай її);
   - ціла плитка — посилання (<Link>) на /?brand=<brandKey>, прокрутка нагору;
   - hover/focus-visible: легке підняття (transform: translateY(-2px)) і помітна рамка; prefers-reduced-motion — без руху;
   - aria-label: «Бренд Barricade, 5 товарів».
   - Функції monogram(name) і brandColor(key) — чисті, у catalog.ts або окремому файлі, з тестами.

3. Блок на головній:
   - розташування: після банера, перед заголовком «Усі товари»; заголовок блоку «Бренди» у тому ж стилі, що «Усі товари», з кількістю брендів;
   - сітка: 3 плитки в ряд на 320–480 px, 4 на планшеті, 6 на десктопі, 8 на широкому (через auto-fill/minmax або брейкпоінти з tokens.css); плитки однакового розміру, нічого не вилазить;
   - якщо брендів більше, ніж влазить у 2 ряди — показати 2 ряди і кнопку «Усі бренди (N)», яка розгортає решту (плавно через motion) і змінюється на «Згорнути»;
   - блок НЕ показується, коли активні будь-які фільтри або відкрита сторінка бренду (isSingleBrandView) — лише на «чистій» головній;
   - поки товари вантажаться — сірі квадрати-заглушки (skeleton) тієї ж сітки; якщо брендів немає — блок не показується.

4. Доступність: блок — <section> з aria-labelledby на заголовок; плитки — список <ul>/<li>; кнопка «Усі бренди» з aria-expanded і aria-controls.

5. Тести: monogram (одне слово, два слова, апостроф/цифри); brandColor детермінований; плитка веде на /?brand=<key>; блок прихований при активних фільтрах і на сторінці бренду; «Усі бренди» розгортає і згортає список.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

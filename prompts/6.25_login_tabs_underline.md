# /login: таби з лінією замість зеленої плашки

Правка вигляду табів «Вхід» / «Вхід для бренду» на /login (frontend/src/features/buyer-auth: LoginPage.tsx, LoginPage.module.css; кольори — shared/tokens.css). Контекст: CLAUDE.md, CSS Modules.

Зараз активний таб — суцільна зелена плашка-кнопка. Так не треба. Має бути:
1. Жоден таб не має заливки фону — обидва прозорі, текст великими літерами як зараз.
2. Під кожним табом лінія на всю його ширину, однакової товщини (2–3 px), обидві лінії на одному рівні й стикуються без проміжку.
3. Активний (вибраний) таб: текст і лінія — зелені (зелений токен з tokens.css, той самий, що зараз).
4. Неактивний таб: текст і лінія — сірі (сірий з палітри tokens.css, наприклад warm-gray/light-gray для лінії і темніший сірий для тексту); контраст сірого тексту з фоном ≥ 4.5:1.
5. Hover на неактивному табі — текст трохи темнішає; focus-visible — помітне обведення лише з клавіатури.
6. При перемиканні зелена лінія плавно переїжджає під новий таб (motion layoutId або transition), prefers-reduced-motion — без анімації.
7. Доступність лишається: role="tablist"/"tab", aria-selected.
8. Онови тести, якщо вони перевіряли класи/стилі активного таба.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

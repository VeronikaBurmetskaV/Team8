# Головна сторінка кабінету бренду /brand і перехід туди після входу

Задача: зробити головну сторінку кабінету бренду і вести туди після входу.

Контекст: кабінет — desktop-first (ADR-0002), Layout.tsx уже дає кабінету широкий контейнер. Зараз після входу/реєстрації pathAfterLogin веде на /brand/products (або /brand/profile, якщо профіль INCOMPLETE). Стилі — CSS Modules + змінні з shared/tokens.css, тексти — українською через messages.uk.ts, як у решті кабінету.

1. Нова сторінка /brand (під RequireBrand, як /brand/profile і /brand/products) — головна кабінету.
2. pathAfterLogin: після входу і реєстрації завжди /brand. Онови pathAfterLogin.test.ts.
3. У навігації кабінету (Layout.tsx) додай «Головна» першим пунктом; логотип/назва FULLA в кабінеті веде на /brand.
4. Вміст головної (дані беремо з наявних запитів useBrandProfile і useBrandProducts, нових ендпоінтів не додавати):
   a) Велика кнопка «Додати товар» по центру сторінки — головна дія: значно більший шрифт і розмір, ніж зараз на /brand/products, кольори акценту з tokens.css, веде на /brand/products/new.
      Якщо профіль INCOMPLETE — замість кнопки та сама підказка, що зараз (messages.PROFILE_INCOMPLETE + посилання «Заповнити профіль бренду»), теж велика й по центру.
   b) Картка профілю бренду: назва бренду, статус згоди (дана / не дана, з датою, якщо дана), кнопка «Редагувати профіль» → /brand/profile.
   c) Короткий підсумок товарів: скільки всього, скільки опубліковано, скільки в чернетках, і посилання «Усі товари» → /brand/products.
   d) Стани завантаження й помилки — як на BrandProductsPage (LoadError, «Спробувати ще раз»). Якщо товарів немає — дружній текст «У вас поки немає товарів» біля кнопки.
5. Картка профілю на /brand/profile: зроби її в 2–3 рази ширшою, ніж зараз (зараз max-width = --auth-card-max-width, як у формі входу). Додай окрему змінну, наприклад --cabinet-card-max-width, у tokens.css, а не міняй --auth-card-max-width, бо вона потрібна сторінкам входу. Більші відступи й шрифт полів відповідно. На вузьких екранах картка на всю ширину.
6. На /brand/products кнопку «Додати товар» теж зроби помітною (як кнопку, а не дрібне посилання), але меншою, ніж на головній.
7. Тести: pathAfterLogin; головна показує кнопку «Додати товар» для активного профілю і підказку для INCOMPLETE; посилання ведуть куди треба.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

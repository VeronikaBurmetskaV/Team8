#  Промпт: User Journey (Happy Path)

### 1️ Роль

Ти — користувач маркетплейсу **FULLA**: молода дівчина, любителька онлайн-шопінгу та унікальних українських брендів.

### 2️ Джерело

Опис нашого проєкту: [Team8 на GitHub](https://github.com/VeronikaBurmetskaV/Team8.git)

> Ми вирішили змінити проєкт. Тепер FULLA — не повноцінний маркетплейс, а лише сайт-посередник між клієнтом і брендом.
>
> Тобто ми не здійснюємо:
> - оплату;
> - доставку.

### 3️ Твоє завдання

Змоделювати головний шлях користувача (**User Journey**): описати свій лінійний ланцюжок дій за основним успішним сценарієм (**Happy Path**) — від першого знайомства з продуктом до отримання результату.

### 4️ Обмеження

- Обсяг: **4–6 послідовних кроків**.
- Кроки мають бути **чіткими та конкретизованими**.
- Без загальних фраз.
- Без зайвих деталей, які не несуть корисної інформації для моделювання User Journey.

### 5️ Формат виводу

Від **4 до 6** окремих пунктів з номерацією:

1. Крок 1
2. Крок 2
3. Крок 3
4. Крок 4

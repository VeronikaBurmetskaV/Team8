# Кружечки розмірів і червона цифра (продовження задачі про розміри)

Переробка показу розмірів на картках (продовження задачі про розміри). Код: features/catalog/CatalogTile.tsx (+ CSS Module), shared/ProductCard (лицьова сторона), features/feed/SwipeCard, shared/SavedProducts, catalog.ts (stockHint, sizeKey, порядок розмірів), shared/messages.uk.ts, shared/tokens.css. Контекст: CLAUDE.md, api.md §2.2 (sizes [{ label, available }] — лише наявність, БЕЗ кількості штук), ADR-0002, CSS Modules.

1. Прибери позначку «Залишилось N розміри» з фото на всіх картках (каталог, свайпи, модалка, обране) — вона перекриває фото. Позначку «Немає в наявності» (коли доступних 0) теж перенеси з фото в інформаційний блок (п. 2).

2. Кружечки розмірів в інформаційному блоці картки (під фото):
   - на картці каталогу (CatalogTile): у рядку з ціною, праворуч від ціни (ціна зліва, кружечки справа, вирівняні по вертикалі з ціною); якщо не влазять поруч — під ціною окремим рядком;
   - на лицьовій стороні картки в свайпах і в модалці — під ціною, як зараз пігулки, але у вигляді кружечків;
   - показувати ЛИШЕ доступні розміри (available: true); недоступні не показувати взагалі (на лицьовій стороні; на зворотній стороні повний список з позначкою «Немає в наявності» лишається);
   - кружечки однакового розміру (~28–32 px на каталозі, трохи більші в свайпах), тонка рамка ink, текст розміру по центру; довгі («One size», «XS/S») — пігулка, а не обрізаний текст;
   - порядок — той самий, що у фільтрі розмірів; якщо не влазять — перші, що влазять, і кружечок «+N»;
   - якщо sizes немає (картки брендів) — нічого не показувати, висота блоку не стрибає;
   - якщо доступних 0 — замість кружечків дрібний сірий текст «Немає в наявності».

3. Червона цифра, коли розмірів лишилось мало:
   - якщо доступних розмірів від 1 до 3 — над групою кружечків (у правому верхньому куті групи, як бейдж сповіщення) маленький червоний кружечок з білою цифрою = кількість доступних розмірів (3, 2 або 1);
   - червоний — новий токен у tokens.css (наприклад --color-danger, насичений червоний з контрастом білого тексту ≥ 4.5:1);
   - aria: група кружечків має aria-label на кшталт «Доступні розміри: S, M. Залишилось 2 розміри» (правильні відмінки), щоб це було зрозуміло не лише за кольором; бейдж aria-hidden;
   - 4 і більше доступних — бейджа немає.
   - Онови stockHint, якщо потрібно, але не дублюй логіку.

4. Свайпи: кружечки не заважають свайпу (pointer-events як у решти тексту картки).

5. Тести: на фото немає позначки «Залишилось…»; показуються лише доступні розміри в правильному порядку; бейдж з числом є при 1–3 доступних і відсутній при 4+; при 0 — текст «Немає в наявності»; картки без sizes нічого не показують; «+N» при переповненні; aria-label групи.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

# Напис про наступний імпорт, розгортання і нові бренди у фільтрі

Три правки: напис про наступний імпорт, розгортання списку брендів у фільтрі, нові бренди у фільтрі. Код: frontend/src/features/cabinet-products (BrandProductsPage) і cabinet-home (блок імпорту), frontend/src/features/catalog (FilterPanel.tsx, CatalogPage.module.css, catalog.ts — brandOptions), запити каталогу й публікації (queries.ts), shared/messages.uk.ts. Контекст: CLAUDE.md, ADR-0002, CSS Modules, motion.

1. Прибери повністю напис «Наступний імпорт можна запустити о HH:MM» скрізь (сторінка товарів бренду і головна кабінету) разом з текстом у messages.uk.ts. «Оновлено: сьогодні о …» лишається.
   - поки діє обмеження частоти, кнопка «Оновити з сайту» неактивна (disabled), а пояснення — лише в атрибуті title / підказці при наведенні («Оновити знову можна о 23:57»), без окремого рядка тексту; коли час минув — кнопка сама стає активною (таймер, без перезавантаження).

2. Розгортання списку брендів у панелі фільтрів:
   - «Показати всі (N)» більше НЕ розширює панель убік і не робить 2–3 колонки: панель лишається звичайної ширини, бренди — в один стовпчик, список просто продовжується вниз;
   - на ноутбуці/десктопі (панель — колонка зліва): коли список розгорнуто, панель перестає бути sticky і не має власного max-height/overflow — вона росте вниз разом з контентом, і користувач гортає саму сторінку; після «Згорнути» панель знову sticky зі своєю прокруткою, як зараз; сітка товарів праворуч не стрибає;
   - на телефоні/планшеті (панель — шухляда поверх сайту) список гортається всередині шухляди — так і лишається; кнопка «Показати N товарів» внизу шухляди лишається закріпленою;
   - пошук «Пошук бренду» лишається над списком;
   - прибери код і стилі розширення панелі вбік (додаткова ширина, grid-колонки), які більше не використовуються; онови тести, що перевіряли розширення.

3. Нові бренди у фільтрі:
   - список брендів у фільтрі будується з тих самих даних, що й плитки брендів (лише бренди з ≥ 1 опублікованим товаром, лічильник — опубліковані);
   - після публікації/зняття з публікації в кабінеті фільтр оновлюється без перезавантаження (ті самі інвалідації запитів, що й для плиток);
   - зареєстровані й імпортовані бренди — один brandKey, без дублів.

4. Тести: напису про наступний імпорт немає, кнопка неактивна під час обмеження і має title; «Показати всі» не змінює ширину панелі і не додає колонок; на десктопі в розгорнутому стані панель не sticky; бренд з'являється у фільтрі після публікації першого товару і зникає після зняття останнього.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

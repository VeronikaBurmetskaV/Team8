# Реєстрація покупця: імʼя обовʼязкове, нова примітка під кнопкою

Правки форми реєстрації покупця (/register). Код: frontend/src/features/buyer-auth (BuyerRegisterPage.tsx, CSS Modules), shared/messages.uk.ts; бекенд — ua.fulla.buyer (реєстрація), Flyway-міграції, docs/architecture/api.md, data-model.md, ADR про поля реєстрації покупця. Контекст: CLAUDE.md, react-hook-form + zod, ADR-0004 (JdbcClient).

1. Поле «Ім'я» тепер ОБОВ'ЯЗКОВЕ:
   - підпис «Ім'я» (без «(необов'язково)»), правильний український апостроф ʼ в усіх текстах («Імʼя»);
   - zod: 1–50 символів після trim, не лише пробіли; помилка «Введіть імʼя»;
   - бекенд: name обов'язкове в POST /api/buyer/register (400 VALIDATION_FAILED з fields.name, якщо порожнє або довше 50); Flyway-міграція — display_name NOT NULL для нових акаунтів (наявні акаунти без імені не ламати: або значення за замовчуванням для старих рядків, або CHECK лише для нових — обери і поясни);
   - онови api.md, data-model.md і ADR (ім'я тепер обов'язкове).

2. Текст під кнопкою «Створити акаунт»:
   - замість «Ми зберігаємо лише ваш email або телефон, імʼя (якщо вкажете) і список вподобаних товарів» → «Ми зберігаємо вашу пошту та вподобані товари»;
   - менший шрифт: на крок менший за поточний (дрібний текст з tokens.css, наприклад --font-size-xs/sm), колір другорядного тексту, контраст ≥ 4.5:1; вміщується в один рядок на десктопі, на телефоні може переноситись.

3. Тести: порожнє ім'я — помилка і запит не відправляється; ім'я з пробілів — помилка; новий текст під кнопкою; бекенд — реєстрація без name → 400 з fields.name.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: cd backend && ./mvnw verify, потім npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

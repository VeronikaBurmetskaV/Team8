# Каталог: виправлення фільтра «Ціна» — поля влазять у панель, кнопка «Показати …», зелений повзунок

Виправлення фільтра «Ціна» в панелі фільтрів каталогу (frontend/src/features/catalog: FilterPanel.tsx, CatalogPage.module.css або окремий CSS Module ціни, catalog.ts, messages.uk.ts). Контекст: CLAUDE.md, ADR-0002 (mobile-first), shared/tokens.css, CSS Modules.

Проблема: рядок [від] грн – [до] грн [ОК] не влазить у ширину панелі, поля стискаються і число обрізається (у полі «до» видно лише «1» замість 10 000).

1. Прибери кнопку «ОК».

2. Поля «від» і «до» завжди влазять і показують число повністю — на будь-якому екрані (від 320 px) і за будь-якої ширини панелі (шухляда на телефоні, колонка на ноутбуці, широкий монітор):
   - рядок: [поле «від»] – [поле «до»]; обидва поля однакові, flex: 1 1 0, min-width: 0, ширина поля вистачає для «10 000» без обрізання;
   - «грн» — всередині поля праворуч (суфікс), а не окремим текстом між полями; над полями маленькі підписи «Від» і «До» (це й label для доступності);
   - число в полях форматується з пробілом тисяч («10 000») при відображенні, а при введенні приймає цифри;
   - адаптивність прив'язана до ширини ПАНЕЛІ, а не вікна: зроби панель container (container-type: inline-size) і через @container — якщо панель вужча за ~260 px, поля стають одне під одним на всю ширину; ширше — в один рядок;
   - нічого в групі «Ціна» не виходить за межі панелі й не створює горизонтального скролу; рамка фокуса заголовка групи теж не обрізається.
   - перевір на ширинах 320, 375, 768, 1024, 1440 px і з відкритою/закритою панеллю.

3. Під повзунком — кнопка застосування замість «ОК»:
   - на всю ширину групи, текст відображає вибраний діапазон і оновлюється наживо: «Показати від 500 до 2 500 грн»; якщо мінімум = 0 — «Показати до 2 500 грн»; якщо максимум = межа — «Показати від 500 грн»; якщо обидва на краях — «Показати всі ціни»;
   - клік застосовує фільтр так само, як раніше «ОК» (оновлює ?minPrice/?maxPrice, на мобільному закриває панель); Enter у полі теж застосовує;
   - якщо діапазон не змінився відносно застосованого — кнопка неактивна (disabled) або прихована;
   - довгий текст переноситься на другий рядок, а не обрізається.

4. Колір повзунка — зелений:
   - додай у shared/tokens.css токен, наприклад --color-green: #5E7046 (приглушений оливковий, пасує до палітри brown/beige); не хардкодь hex у CSS Module;
   - зеленим — активна частина лінії між ручками і рамка ручок; неактивна частина лінії — світла (light-gray з палітри); ручки — білі з зеленою рамкою; стан фокусу ручки — помітне зелене обведення;
   - перевір контраст: активна лінія й рамка ручок мають контраст ≥ 3:1 з фоном панелі (WCAG для нетекстових елементів); якщо ні — затемни відтінок і скажи, який вийшов;
   - кнопку «Показати…» теж можна зробити в цьому зеленому (текст білий, контраст тексту ≥ 4.5:1) — якщо контраст не проходить, лиши її темною (ink).

5. Тести: кнопки «ОК» немає; текст кнопки змінюється за діапазоном (4 варіанти); клік і Enter застосовують фільтр; кнопка неактивна, коли діапазон не змінено. Онови тести, які чекали «ОК».

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли й вибраний відтінок зеленого.

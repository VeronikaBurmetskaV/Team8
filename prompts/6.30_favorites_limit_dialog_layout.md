# Вікно «Вподобане заповнене»: хрестик замість «Скасувати», кнопки в ряд, новий текст

Правка вікна «Вподобане заповнене» (ліміт вподобаного). Знайди компонент вікна (ймовірно shared ConfirmDialog або окремий FavoritesLimitDialog) і тексти в shared/messages.uk.ts. Контекст: CLAUDE.md, ADR-0002, shared/tokens.css, CSS Modules.

1. Прибери кнопку «Скасувати». Замість неї — кнопка-хрестик ✕ у правому верхньому куті вікна:
   - іконка з shared/icons.tsx, зона натискання ≥ 44×44 px, aria-label «Закрити»;
   - закриває вікно так само, як раніше «Скасувати» (товар не додається); Esc і клік по затемненому фону теж закривають;
   - при відкритті фокус на першій дії вікна або на ✕ (не на заголовку), після закриття — повертається на сердечко/кнопку, з якої відкрили;
   - хрестик не накладається на заголовок: заголовок має відступ справа під ширину кнопки.

2. Текст для гостя: «Щоб зберігати більше товарів",  створіть акаунт.  Або звільніть місце у вподобаному.»(замість «Щоб зберігати до 100 товарів…»). Для акаунта текст лишається як є.

3. Заголовок не розривається посередині числа: «Вподобане заповнене (25 з 25)» — між «25», «з», «25» нерозривні пробіли ( ), щоб «(25 з 25)» завжди був на одному рядку.

4. Кнопки «Перейти у вподобане» і «Зареєструватися» — в одному ряду, однакової ширини (по 50%, з проміжком між ними), однакової висоти, вирівняні по нижньому краю вікна:
   - «Зареєструватися» — головна (заливка тим самим кольором, що й інші головні кнопки сайту — зелений токен, якщо головні кнопки вже зелені), «Перейти у вподобане» — другорядна (рамка);
   - на вузьких екранах (≤ 360 px або коли текст не влазить) кнопки стають одна під одною на всю ширину: спершу «Зареєструватися», потім «Перейти у вподобане»;
   - для акаунта (де кнопка лише «Перейти у вподобане») — одна кнопка на всю ширину.

5. Онови тести вікна: немає «Скасувати», є ✕ з aria-label «Закрити», ✕/Esc закривають без додавання товару, новий текст, обидві кнопки присутні.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

# «Вподобане»: компактна картка, хрестик з підтвердженням, повна картка в модальному вікні

Правки карток на сторінках обраного (/favorites і /swipe-favorites). Обидві використовують shared/SavedProducts/SavedProducts.tsx, а він — shared/ProductCard/ProductCard.tsx (той самий, що на свайпах у features/feed). Контекст: CLAUDE.md, ADR-0002 (покупець mobile-first), shared/tokens.css, CSS Modules, motion, тексти в shared/messages.uk.ts. Бекенд не чіпаємо. Свайп-стрічку (features/feed) не змінювати.

1. Картка в списку обраного — компактна, без перевертання:
   - прибери кнопку «Прибрати» під карткою;
   - прибери кнопку «Перевернути» і сам переворот у списку (для цього додай у ProductCard проп, наприклад variant="compact" або flippable={false}; поведінка на свайпах лишається як є);
   - кнопка «Перейти на сайт бренду» лишається.

2. Хрестик видалення:
   - у правому верхньому куті фото — кругла кнопка з іконкою хрестика (іконку додай у shared/icons.tsx, якщо немає), напівпрозорий фон з tokens.css, щоб було видно на будь-якому фото; розмір зони натискання не менше 44×44 px; aria-label — наявний removeLabel(name).
   - натискання на хрестик: фото цієї картки розмивається (filter: blur, плавно через motion) і з'являється вікно підтвердження «Впевнені, що хочете видалити товар?» з кнопками «Видалити» і «Скасувати».
   - «Видалити» — товар прибирається зі списку (та сама логіка, що зараз у кнопки «Прибрати»), картка плавно зникає.
   - «Скасувати», Esc або клік поза вікном — вікно закривається, блюр знімається.
   - Якщо в проєкті вже є shared/ConfirmDialog (з попередньої задачі про вихід із профілю) — використай його; якщо ні — створи перевикористовуваний компонент на нативному <dialog> (showModal, фокус на «Скасувати», Esc закриває, фокус повертається на хрестик).

3. Відкриття картки на весь екран:
   - клік (або Enter/Space з клавіатури) по будь-якій частині картки, крім хрестика і «Перейти на сайт бренду», відкриває модальне вікно з повною карткою товару — такою ж, як на свайпах (ProductCard з перевертанням і всією інформацією), плюс кнопка «Перейти на сайт бренду».
   - фон сторінки під вікном розмивається (backdrop-filter: blur + затемнення з tokens.css), скрол сторінки блокується, поява/зникнення через motion.
   - закриття: кнопка-хрестик у вікні, Esc, клік по фону; фокус повертається на картку, з якої відкрили.
   - на мобільному (від 320 px) картка у вікні вписується в екран без горизонтального скролу; на десктопі — розмір як на свайпах.
   - клік по хрестику видалення і по «Перейти на сайт бренду» НЕ відкриває модалку (зупинити спливання події).
   - доступність: картка в списку — кнопка/елемент з role="button", tabIndex=0 і зрозумілим aria-label («Відкрити картку: <назва>»); модалка — role="dialog", aria-modal, aria-labelledby на назву товару.

4. Прибери з messages.uk.ts тексти, які більше не використовуються («Прибрати»), додай нові (текст підтвердження, кнопки, aria-label).

5. Тести: хрестик відкриває підтвердження і блюрить фото; «Скасувати» нічого не видаляє; «Видалити» прибирає товар; клік по картці відкриває модалку з перевертанням; клік по хрестику/посиланню модалку не відкриває; Esc закриває обидва вікна. Перевір, що тести свайп-стрічки не зламались.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

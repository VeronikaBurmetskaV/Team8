Act as a full-stack developer on the FULLA team. Fix the significant findings

`CLAUDE.md` as binding rules. Change only what each finding requires.

### 4 Завдання

**№1 Line endings.** Add `.gitattributes`: `* text=auto eol=lf`,
`*.cmd text eol=crlf`, binary files (`*.png`, `*.jpg`, `*.webp`, `*.jar`) as
`binary`. Run `git add --renormalize .`. `npm run lint` must pass on Windows.

**№2 CI and PR template.** Add `.github/workflows/ci.yml` (on push and pull
requests to `main`): `actions/setup-java` Temurin 21 with Maven cache,
`actions/setup-node` from `.nvmrc` with npm cache, `npm ci`, `npm run lint`,
`npm run typecheck`, `npm --workspace frontend run test`,
`cd backend && ./mvnw -B verify`. Add `.github/pull_request_template.md` with
the checklist from `CLAUDE.md` §7.

**№3 Logo in `PUT /api/brand/profile`.** Until the logo is implemented, a
non-null `logoImageId` or non-empty `logoUrl` → `400 PROFILE_INVALID` with
`fields.logo`, instead of silently ignoring it. Name saving stays as is.
Add backend tests.

**№4 README demo section.** I explicitly allow editing `README.md` for this.
Add a section «Демо ітерації 5» after «Локальний запуск»: 6–8 numbered steps
with URLs (`/brand/register`, `/brand/profile`, `/brand/products/new`,
`/brand/products`), sample data (`Лляна сукня міді`, `2400`,
`https://brand-site.ua/linen-dress`, a PNG/JPG/WEBP photo up to 5 MB or an
`https://` image URL), the restart step (Ctrl+C → `npm run dev` →
`/brand/login`, sessions are in memory so log in again, cards stay), the
expected result of each step, and how to stop the app correctly on Windows.
Write it in Ukrainian, short.

**№5 Leftover Postgres on Windows.**
- `scripts/dev.mjs`: on Windows stop the whole process tree with
  `spawnSync("taskkill", ["/pid", String(child.pid), "/T", "/F"])`; keep
  the current behaviour on macOS/Linux.
- `DevDatabaseConfig`: before `start()`, check the port is free
  (`new ServerSocket(PORT)` in try-with-resources); if busy, fail with
  «Порт 15432 зайнятий — зупиніть старий postgres.exe (Диспетчер завдань)».

**№6 FE/BE validation mismatch.** Make both sides accept exactly the same
URLs, using the **backend as the reference**:
- remove the `i` flag from `isHttpsUrl` (only lowercase `https://`);
- frontend rejects hosts the backend rejects (non-ASCII/IDN like `.укр`,
  underscore in host) — the IDN decision is recorded as «MVP: не
  підтримуємо, Post-MVP: IDN.toASCII»;
- move the URL examples into one `frontend/src/shared/validation.examples.json`
  read by both Vitest and JUnit (`@MethodSource` reading the file), so the
  examples can't drift again.

**№7 mvnw path.** In `scripts/dev.mjs` and `scripts/mvnw.mjs` call
`mvnw.cmd` / `mvnw` by full path (`path.join(backendDir, …)`).

### 5 Обмеження

- Do not change endpoints, error codes or fields beyond №3; do not edit
  `docs/adr/`, `docs/architecture/`, `user stories/`. If a fix needs a contract
  change, stop and ask.
- No new libraries outside the allow-list in `CLAUDE.md` §2.3.
- Do not weaken or skip existing tests; every behaviour change gets a test.
- Do not merge into `main`.

### 6 Формат виводу

1. Run and report: `npm run lint`, `npm run typecheck`, `npm test`,
   `npm run build`, `cd backend && ./mvnw verify`.
2. Run `npm run dev`, stop it with Ctrl+C, and confirm no `postgres.exe` or
   `java.exe` from this project is left (`Get-Process`).
3. Table: finding № → what changed (files) → test.
4. One commit per finding (messages name the finding), push
   `fix/final-review`, and give me a ready PR description.

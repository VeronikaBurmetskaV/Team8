# Розміри на картці товару і позначка «мало розмірів»

Розміри на картці товару і позначка «мало розмірів». Код: frontend/src/shared/ProductCard (лицьова і зворотна сторона, переворот), features/feed (SwipeCard), shared/SavedProducts (повна картка в модалці), features/catalog/CatalogTile.tsx, catalog.ts (sizeKey, порядок розмірів з фільтра розмірів — перевикористай, не дублюй), shared/messages.uk.ts. Контекст: CLAUDE.md, api.md §2.2 (FeedCard: sizes [{ label, available }], colors, material, description — лише в імпортованих картках, у карток брендів полів немає), ADR-0002, shared/tokens.css, CSS Modules, motion. Бекенд не змінюємо.

1. Лицьова сторона картки (до перевороту) — у свайпах і в повній картці в модалці обраного:
   - під ціною рядок розмірів: компактні «пігулки» з написом розміру в правильному порядку (той самий порядок, що в фільтрі розмірів);
   - доступні (available: true) — звичайні; недоступні — сірі й перекреслені, з aria-label «M — немає в наявності»; якщо розмірів багато й не влазять в один рядок — показати ті, що влазять, і «+3» (без переносу на кілька рядків, щоб картка не росла);
   - якщо поля sizes немає (картки брендів) — рядок не показується, висота картки не стрибає;
   - розміри на лицьовій стороні лише показуються (не кнопки), не заважають свайпу.

2. Зворотна сторона картки — вся детальна інформація:
   - «Розміри» — усі розміри повністю (доступні й недоступні, як на лицьовій), з підписом «Немає в наявності» для недоступних;
   - «Колір» (colors), «Матеріал» (material), «Опис» (description) — кожне лише якщо є; опис прокручується всередині картки, якщо довгий;
   - бренд, назва, ціна і кнопка «Перейти на сайт бренду» — як зараз;
   - перевір, що на лицьовій стороні більше не дублюється детальна інформація, яка тепер на звороті.

3. Позначка «мало розмірів»:
   - якщо в товару є sizes і доступних розмірів від 1 до 3 включно — показати помітну позначку: «Залишилось 3 розміри» / «Залишилось 2 розміри» / «Залишився 1 розмір» (правильні відмінки; якщо є функція відмінювання — використай її);
   - вигляд: невеличка пігулка з акцентним кольором (accent #CB8F00 з tokens.css або окремий токен попередження) і темним текстом, контраст ≥ 4.5:1, у верхньому лівому куті фото (не накладається на сердечко/хрестик справа);
   - показувати на: картці в каталозі (CatalogTile), лицьовій стороні в свайпах, у повній картці в модалці, на картках в обраному;
   - доступні розміри в рядку пігулок (п. 1) у такому товарі злегка підсвічені тим самим акцентним кольором;
   - якщо доступних 0 (усе розпродано) — замість цього сіра позначка «Немає в наявності»;
   - логіку винеси в чисту функцію stockHint(sizes) → { kind: 'few', count } | { kind: 'none' } | null у catalog.ts або shared.

4. Доступність: позначка — текстом, не лише кольором; пігулки розмірів — список з aria-label «Розміри»; на звороті заголовки секцій.

5. Тести: stockHint (немає sizes → null; 4+ доступних → null; 3/2/1 → few з правильним числом; 0 доступних → none); відмінки тексту; лицьова сторона показує розміри в правильному порядку, недоступні перекреслені; «+N», коли не влазять; зворотна сторона показує колір/матеріал/опис лише коли є; позначка є в CatalogTile, SwipeCard, модалці й обраному.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

# Промпт: Початковий каркас проєкту (Skeleton, Root, Backend, Frontend)

Create the project skeleton from `docs/adr/` and `docs/architecture/`. Follow `CLAUDE.md`. **No business logic.**

## 1 Root

Workspace and tooling at the repository level:

- npm workspaces, `package.json` with `dev` / `build` / `typecheck` / `test` scripts for the project;
- `scripts/dev.mjs`;
- `.nvmrc`;
- `.env.example`;
- `README.md` with local launch instructions in **1–2 commands**.

## 2 Backend

**Java 21 + Spring Boot 3.x** with Maven Wrapper.

- Libraries according to `CLAUDE.md`: Spring Web, Spring Security, Bean Validation and `JdbcClient`;
- database: PostgreSQL, with embedded PostgreSQL (Zonky) for local development;
- migrations: initial Flyway migration from `data-model.md`;
- endpoint: `GET /api/health`;
- structure: package structure and API conventions from the architecture documents;
- **no business logic**.

## 3 Frontend

**Vite + React + TypeScript**.

- routing: React Router with stubs for all planned FULLA pages from `overview.md` (each — a heading with the page name);
- API: a client for `GET /api/health`;
- dev server: Vite proxy to the backend on port `8080`;
- styling: no styles except a minimal layout with the **FULLA** name.

## 4 Verification

After creating the skeleton:

1. run `npm install`;
2. run the available `build` / `typecheck` / `test` commands;
3. fix everything that fails.

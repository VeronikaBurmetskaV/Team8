# Єдина сторінка входу /login з табами «Вхід» / «Вхід для бренду»

Контекст: проєкт FULLA (див. CLAUDE.md, docs/architecture/api.md, ADR-0002). Frontend: React + Vite + TS strict, CSS Modules, react-hook-form + zod, @tanstack/react-query, motion. Палітра — shared/tokens.css. Бекенд НЕ змінюємо.

Завдання: зробити єдину сторінку входу /login з перемикачем «Вхід» / «Вхід для бренду».

1. Шапка покупця: іконка профілю (людина) веде на /login.

2. Сторінка /login (зараз там заглушка — замінити):
   - Зверху два широкі кнопки-таби на всю ширину картки, поруч, 50/50:
     зліва «Вхід», справа «Вхід для бренду». Активний таб візуально виділений (кольори з tokens.css, accent/brown), неактивний — приглушений.
   - Під табами — картка з формою, яка змінюється при перемиканні табу (плавний перехід через motion, без різких стрибків висоти).
   - Активний таб зберігається в URL: /login (покупець, за замовчуванням) і /login?tab=brand. Перезавантаження сторінки зберігає таб.

3. Таб «Вхід» (покупець) — тимчасово:
   - Вхід для покупця ще не реалізований. Показати в картці текст-заглушку «Тут скоро буде вхід для покупця» (без полів і без запитів на бекенд).
   - Внизу картки: «Немає акаунту? Створити» — поки неактивне/заглушка (не веде на неіснуючу сторінку).

4. Таб «Вхід для бренду»:
   - Перевикористати наявну логіку та форму з /brand/login (поля, валідація zod, запит, обробка помилок, редірект після успіху — як зараз). НЕ дублювати код: винести форму в окремий компонент, якщо вона ще не окрема, і використати її і тут, і там.
   - Внизу картки: «Немає акаунту? Зареєструвати бренд» → посилання на /brand/register.

5. /brand/login: зробити редірект на /login?tab=brand (щоб старі посилання працювали).

6. Адаптивність: покупецька частина — mobile-first (ADR-0002). На мобільному картка на всю ширину з відступами, таби не переносяться в два рядки (якщо текст не влазить — зменшити шрифт, не обрізати).

7. Доступність: таби — role="tablist"/"tab"/"tabpanel", aria-selected, перемикання стрілками клавіатури.

8. Якщо в проєкті вже є UA/EN локалізація — додати всі нові тексти в обидві мови. Якщо немає — тексти українською.

9. Тести: перемикання табів, синхронізація з ?tab=brand, редірект з /brand/login, посилання на /brand/register, заглушка на табі покупця.

10. Збережи цей промпт у prompts/ з наступним порядковим номером (подивись, які номери вже є).

Наприкінці прогони: npm run lint, npm run typecheck, npm test, npm run build. Виправ усі помилки. Коротко опиши, які файли змінено.

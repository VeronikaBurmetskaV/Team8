# Дії у списку товарів бренду: зняття з публікації, «Редагувати», масові дії

Правки дій у списку товарів бренду (/brand/products). Код: frontend/src/features/cabinet-products (BrandProductsPage.tsx, CSS Module, queries.ts, api), shared/messages.uk.ts; бекенд — публікація товарів бренду. Контекст: CLAUDE.md, docs/architecture/api.md (публікація/статуси товару), domain-model.md (переходи статусів товару), ADR-0002, CSS Modules.

1. Зняття з публікації:
   - у рядку опублікованого товару (зараз там немає жодних дій) — кнопка «Зняти з публікації» (другорядна, з рамкою; наведення — зелена рамка й текст), на тому ж місці, де в чернетки «Опублікувати у стрічку»;
   - перед зняттям — підтвердження через наявний ConfirmDialog: «Зняти товар з публікації? Покупці більше не побачать його в стрічці й каталозі.» кнопки «Зняти» і «Скасувати»;
   - після зняття товар стає «Чернетка», зникає з каталогу/свайпів для покупців (інвалідуй відповідні запити react-query); статус і кнопка в рядку оновлюються;
   - бекенд: перевір, чи є ендпоінт зняття з публікації (за api.md / domain-model.md); якщо немає — додай (наприклад POST /api/brand/products/{id}/unpublish та масовий варіант), з перевіркою, що товар належить цьому бренду; онови api.md.
   - товар зі статусом «Немає на сайті» — без кнопок публікації/зняття (як зараз задумано).

2. Розташування дій у рядку (і для чернетки, і для опублікованого):
   - праворуч у стовпчик: зверху головна дія («Опублікувати у стрічку» або «Зняти з публікації»), ПІД нею посилання «Редагувати» (вирівняне по центру або по правому краю під кнопкою, з невеликим відступом);
   - у опублікованого товару «Редагувати» теж є (зараз немає);
   - кнопки однакової ширини в усіх рядках, щоб стовпчик дій був рівним.

3. Вибір кружечками: кружечок вибору є в усіх рядках (і в опублікованих — зараз його там немає), крім «Немає на сайті».

4. Масові дії над таблицею:
   - поміняй місцями: ліворуч «Опублікувати всі чернетки (N)», праворуч «Опублікувати вибрані (N)»;
   - якщо серед вибраних є опубліковані — поруч з'являється «Зняти вибрані з публікації (N)» (з тим самим підтвердженням); «Опублікувати вибрані» рахує лише чернетки серед вибраних;
   - неактивні кнопки (N = 0) — приглушені, як зараз.

5. Тести: «Зняти з публікації» з підтвердженням змінює статус на «Чернетка» і товар зникає з публічного списку; «Скасувати» нічого не змінює; «Редагувати» є під головною дією в обох типах рядків; порядок масових кнопок; масове зняття вибраних; бекенд — зняття чужого товару заборонене, зняття змінює статус.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: cd backend && ./mvnw verify, потім npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.

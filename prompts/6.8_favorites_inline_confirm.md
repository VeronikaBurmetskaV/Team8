# «Вподобане»: підтвердження видалення всередині картки, посилання на бренд лише у відкритій картці

Правки до попередньої задачі про картки обраного (shared/SavedProducts, shared/ProductCard). Контекст той самий: CLAUDE.md, ADR-0002, shared/tokens.css, CSS Modules, motion, messages.uk.ts. Свайп-стрічку (features/feed) не змінювати.

1. Підтвердження видалення — всередині картки, а не по центру екрана.
   - Після натискання хрестика фото картки розмивається (як зараз), і ПОВЕРХ цієї ж картки (по центру розмитого фото) з'являється невеликий блок: текст «Впевнені, що хочете видалити товар?» і дві кнопки «Видалити» і «Скасувати». Модальне вікно по центру екрана для цього більше не використовувати.
   - Блок у межах картки, з напівпрозорим фоном з tokens.css, щоб текст читався на будь-якому фото; поява через motion.
   - Поки блок відкритий: хрестик схований, клік по картці НЕ відкриває повну картку, інші картки працюють як зазвичай.
   - Доступність: блок role="alertdialog" з aria-labelledby на текст питання; фокус переходить на «Скасувати»; Esc = «Скасувати»; після закриття фокус повертається на хрестик (або на наступну картку, якщо товар видалено). Відкритим може бути лише одне таке підтвердження одночасно.
   - «Видалити» — товар зникає зі списку з анімацією; «Скасувати» — блюр знімається.
   - Якщо ConfirmDialog (по центру екрана) більше ніде на цих сторінках не використовується — не видаляй його з shared/, він потрібен для виходу з профілю бренду.

2. Прибери кнопку «Перейти на сайт бренду» з карток у списку обраного. Вона лишається ТІЛЬКИ у відкритій (повній) картці в модальному вікні.
   Після цього вся картка в списку — одна область для кліку (крім хрестика).

3. Кнопка «Перейти на сайт бренду» у відкритій картці зараз зливається з фоном. Зроби її помітною:
   - заливка акцентним кольором --accent (#CB8F00) з tokens.css і темний текст (ink), або, якщо контраст недостатній, світлий фон з рамкою 2px кольору ink — обери варіант з контрастом тексту не менше 4.5:1 (WCAG AA) і поясни вибір у відповіді;
   - чіткі стани hover і focus-visible (рамка/обведення), не лише зміна кольору;
   - кнопка на всю ширину картки, під нею, не перекривається розмитим фоном;
   - колір бери з токенів, не хардкодь hex у CSS Module; якщо потрібен новий токен — додай у tokens.css.

4. Онови тести: підтвердження рендериться всередині картки (не в document.body-модалці); клік по картці під час підтвердження не відкриває повну картку; у списку немає посилання «Перейти на сайт бренду», у відкритій картці воно є; Esc закриває підтвердження без видалення.

Збережи цей промпт у prompts/ з наступним номером.
Наприкінці: npm run lint, npm run typecheck, npm test, npm run build. Коротко опиши змінені файли.
